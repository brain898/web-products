STYLE 01
OpenAI / Anthropic 风
纯黑底 + 沿用现有橙色单一强调。最克制，改造成本最低（沿用现有 logo / 数据 / 字体）。类比 OpenAI、Anthropic 官网那种高级克制感。

STYLE 02
Linear / Vercel 紫蓝产品风
深紫黑底 + 紫蓝强调，玻璃拟态卡片 + 微发光 + 渐变色块。SaaS 产品工程师调，未来感更强但稍花。
VIEW →
STYLE 03
深蓝赛博 / Raycast 风
深蓝黑底 + 青蓝强调，网格背景 + 等宽字体 + 终端味（命令行风的导航 / 代码片段感）。极客赛博感最强。
VIEW →
STYLE 04
深灰 + 银白 Apple 风
深灰底 + 银白主导 + 微量橙色点缀。最冷静最克制，超细字重 + 大量留白。平静质感而不是击中感。
