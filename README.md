# Web Products Collection

这个仓库包含了我通过 AI 辅助开发落地的三个独立网页产品。这些项目展示了从需求分析、AI 对话生成代码到部署上线的完整闭环。

## 📦 项目列表

### 1. [问卷悬赏系统](./survey-bounty/)
- **简介**：一个带有悬赏机制的问卷系统。
- **技术栈**：Next.js, Tailwind CSS, TypeScript
- **展示地址**：[https://survey.wzye.top/](https://survey.wzye.top/)

### 2. [个人主页/介绍页](./personal-intro/)
- **简介**：响应式的个人介绍静态页面。
- **展示地址**：[https://wzye.top/](https://wzye.top/)

### 3. [生日祝福互动页](./birthday-wish/)
- **简介**：带有特效和音乐的生日祝福页面。
- **展示地址**：[https://challenge.wzye.top/](https://challenge.wzye.top/)

## 🚀 开发方法论

这些项目都使用了 **AI 工作流** 开发：
1. **需求澄清**：使用自研提示词与大模型对话，明确目标和边界。
2. **代码生成**：使用 Claude/Gemini 等大模型生成前端和逻辑代码。
3. **部署上线**：使用 Vercel, Cloudflare Pages 等平台部署，绑定自定义域名。
